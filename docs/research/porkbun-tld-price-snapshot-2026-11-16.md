# Porkbun list prices for common domain endings, with a dated comparison

Status: read from https://porkbun.com/products/domains on 2026-11-16. The page says prices are USD, for non-premium single-year registrations, renewals and transfers, and include ICANN and other fees. First-year sale prices can end. Treat every figure as a dated snapshot, and check the page again before buying.

| .dev | $8.75 | $12.87 |
| .app | $8.75 | $14.93 |
| .co | $15.76 | $31.20 |
| .io | $28.12 | $51.80 |
| .com | $11.81 (no sale shown) | $11.81 |
| .net | $12.52 (no sale shown) | $12.52 |
| .id | $18.33 (no sale shown) | $18.33 |

The column order on the page is registration, renewal, transfer; the table reads the first two. For .id, whether a Porkbun registration needs Indonesian-resident documents was not checked.

## Compared with an earlier read of the same page
- On 2026-10-24 the same page showed .org $7.98 / $11.84, .dev $8.75 / $12.87, .io $28.12 / $51.80 and .co $15.76 / $31.20 (first year / renewal). Those match today.

## Reading a sale price
A low first year is not the cost of keeping the name. Compare the renewal column. Open question, not checked from a current official source: some endings carry extra rules (for example an HTTPS-only rule on .dev, or residency documents for .id). Check the registry's own page for the ending before buying.
